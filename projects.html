Business concept & web prototype

WCin

A digital marketplace concept connecting households and businesses in Bekasi with septic-tank and sanitation service providers. The project explores clearer pricing, easier booking, and greater trust in service partners.

Business modelUser researchUI/UX prototype

Prototype screenshot; figures and service claims are illustrative.

Open WCin prototype (new tab)
Explore WCin

The challenge

Finding sanitation services can involve unclear prices, uncertain arrival times, and difficulty assessing provider quality.

The proposed solution

  • A service catalog, booking flow, and price estimates.
  • Partner profiles, ratings, and a service-tracking concept.
  • Maintenance reminders and digital service records.

Project deliverables

User personas, empathy maps, a value proposition canvas, business-model analysis, and a web prototype. This is a university concept project, not a claim of an operating marketplace.

Programming for Business · web application

EcoWise

A sustainability-focused web application supporting SDG 12: Responsible Consumption and Production. It brings everyday consumption tracking, food-expiry management, and community sharing into one interface.

PHPMySQLHTML / CSSSDG 12

Application screenshot from the project report.

Explore EcoWise

Key features

  • An illustrative consumption and carbon-impact calculator.
  • Food-expiry tracking to help reduce waste.
  • Sustainable product recommendations.
  • Community posts for donations, swaps, and food sharing.
  • Eco-challenges with a points and rewards demonstration.

Project deliverables

PHP application code, a SQL database, interface styling, an ERD, and a page map.

Learning focus

The team report highlights organizing data across several features and keeping a single-page interface clear and consistent. The source project requires a PHP and MySQL environment; this portfolio presents its overview.

Information System Project Management · case study

Kedai Kopi Tiam

An academic project-management plan for an integrated information system across a ten-outlet coffee business. It connects operational needs with a structured plan for scope, schedule, budget, risk, and rollout.

Microsoft ExcelDraw.ioProject planning

Work breakdown structure from the case-study documentation.

Explore Kedai Kopi Tiam

The business scenario

The case study considers disconnected point-of-sale systems, manual reporting, and stock information that is not updated in real time.

Planned system

Integrated POS, inventory and purchasing, management dashboards, digital payments, and loyalty membership.

Planning deliverables

  • Project charter and work breakdown structure.
  • Gantt chart and activity network diagram.
  • Cost estimates, RACI matrix, and risk planning.
  • Stakeholder analysis and communication planning.

Case-study scope

The plan uses a five-month schedule and a Rp 1.2 billion baseline budget. These are academic planning assumptions, not a delivered commercial implementation. The simulated project charter names me as Project Manager.

Programming for Business · web application

Kenangan Kopi

Named KenanginKopi in the project files, this coffee-store web application brings branch discovery, coffee menus, a shopping cart, and order history together, with separate customer and administrator areas.

PHPMySQLJavaScriptHTML / CSS

Original logo asset included in the project.

Explore Kenangan Kopi

Customer experience

  • Browse and search store branches.
  • Register, sign in, and manage a profile.
  • Browse coffee menus and manage a cart.
  • Create an order record and review purchase history.

Administration

Dedicated pages manage coffee products, stores, store-specific menus, and users.

Project deliverables

PHP pages, JavaScript interactions, CSS styling, and a MySQL database script. Checkout records transactions within the application; a live payment-gateway integration is not claimed. This portfolio presents the project rather than hosting its backend.
